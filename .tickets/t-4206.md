# Optimize migrate-beads command: faster import

How: stream entries once with serde, validate required fields, and preserve note formatting; Why: avoid large temp files and improve data fidelity.

## Implementation plan

- Refactor `cmd_migrate_beads` to stream input line-by-line into a single processing pipeline: parse JSON (via serde) and immediately emit markdown, avoiding intermediate large vectors.
- Validate required fields (`id`, `status`, `title`) and skip/flag malformed records with a warning count; continue processing.
- Preserve multi-line note formatting by writing notes exactly as provided, ensuring trailing newlines and separating sections with blank lines.
- Add tests with synthetic `.beads/issues.jsonl` covering blocks/related/parent types, malformed entries, and multiline notes.

## Changes made
