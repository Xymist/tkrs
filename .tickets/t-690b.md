# Optimize unlink command: shared helper

How: reuse the link-set helper with idempotent writes and optional warning when a link is missing; Why: avoid double parsing and accidental asymmetry.

## Implementation plan
- Extract a shared link-set update helper used by both `link` and `unlink`, operating on in-memory sets and writing each ticket once only if changed.
- Make unlink idempotent: if the link is absent, optionally print a warning flag (e.g., `--warn-missing`) but do not error.
- Ensure symmetry by updating both ends via the helper and skipping writes when unchanged to reduce disk churn.
- Add tests for missing-link warning, symmetric unlink, and no rewrite when already unlinked.
