# tk tree/graph: --root with --inverted scopes by walk direction instead of dependency closure

tk graph --root <epic> --inverted (and tk tree equivalently) emits only the root node: --inverted changes the walk direction from the root, and an epic has no dependants. Intended semantics: --root selects the scope (the ticket plus its selection-filtered dependency closure, i.e. exactly what the normal-orientation --root walk reaches); --inverted then renders that scope leaf-first. Implementation: compute the closure subset via the normal walk, then run the standard unrestricted inverted assembly (forest or graph) over that subset. Normal-orientation --root behaviour is unchanged. Trade-off: --root <leaf> --inverted no longer means "all transitive dependants of leaf".
