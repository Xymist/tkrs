# Optimize dep cycle command: clearer detection

How: share the graph builder with dep tree, add --include-closed, and normalize cycle output; Why: reduce duplicate parsing and surface actionable cycles.

## Implementation plan

- Extract a shared graph builder that returns `(tickets, graph)` from `read_all_tickets()` in `src/main.rs` and accepts a `include_closed: bool` flag; reuse it in both `dep_tree` and `dep_cycle` to avoid re-parsing.
- Add a `--include-closed` flag to `DepAction::Cycle` args; default to current behavior (open/in_progress only) to keep output tight.
- Normalize output by printing a header and one line per cycle with canonical ordering (rotate so smallest id first, join with ` -> `) to dedupe equivalent cycles.
- Add tests in `tests/cli.rs` covering open-only vs include-closed cycles and normalized ordering on a simple graph.
