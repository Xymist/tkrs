# Set or update --external-ref on an existing ticket

external_ref can only be set at creation time (CreateArgs in src/cli.rs). GitHub issues are regularly opened after the local ticket exists, so there must be a non-interactive way to add or change the external ref on an existing ticket without hand-editing the Markdown.

## Implementation Plan

Add a non-interactive setter, e.g. --external-ref on tk edit alongside the body-section flags, or a tk set <id> external-ref <value> style subcommand — keep the choice consistent with whatever shape the body-update ticket lands on. Should validate/normalise the same way create does and support clearing the ref.

## Acceptance Criteria

An existing ticket can have its external ref added, changed, and cleared non-interactively; the value round-trips through show/query JSON identically to one set at creation; help text documents it.
