# All tickets should have a standard template on creation

Ticket markdown files should always be created from a standard template, with every section present even when content is not supplied at creation time. Currently write_ticket (src/fs.rs:148) emits each part only when its value is present: the lead description is written only if set, and the ## Implementation Plan, ## Acceptance Criteria, and ## Notes headings appear only when their content is non-empty. As a result, a ticket created without --description / --implementation-plan / --acceptance is missing those headings entirely. Instead, the headings should always be present, and any section whose body was not provided should contain a single `-` placeholder character.

## Implementation Plan

- Update write_ticket (src/fs.rs:148) to always emit the lead description plus the ## Implementation Plan, ## Acceptance Criteria, and ## Notes headings.
- When a section has no content, write a single `-` as its body rather than omitting the heading. Decide how to handle Notes, which is a list appended to via add-note.
- Reconcile with the Display impl for TicketBody (src/lib.rs:781), which already prints all headings but substitutes empty strings instead of `-`; on-disk and displayed formats should agree.
- Ensure parse_ticket (src/fs.rs) round-trips a `-` body: write -> parse -> write must be stable, with no duplicated or dropped headings. Prefer treating a lone `-` as empty on load so a later edit replaces it.
- Add tests: creating a ticket with only a title yields the full template with `-` bodies, and a write/parse/write round-trip is stable.

## Acceptance Criteria

- A ticket created with only a title contains all standard sections (lead description, Implementation Plan, Acceptance Criteria, Notes) in its markdown file.
- Each section not supplied at creation shows a single `-` as its body.
- Sections supplied at creation render their provided content unchanged.
- Write -> parse -> write is stable: no heading duplication or loss.
- cargo nextest run, cargo clippy, and cargo fmt all pass.
