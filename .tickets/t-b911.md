# Optimize dep command: safe add with cycle guard

How: update deps via in-memory set logic, check for ambiguous IDs, and run optional pre-cycle detection; Why: avoid brittle text rewrites and prevent bad edges.

## Implementation plan

- Refactor `dep_add` to resolve both ids with the existing partial-id resolver; if ambiguous, return a clear error before writing.
- Maintain deps as a set in memory (sorted/deduped) and write once; reuse a shared helper also used by `undep` to avoid repeated file parsing.
- Add an optional `--check-cycle` flag that runs `dep_cycle` logic after adding and reverts the write if a new cycle is introduced.
- Add tests for ambiguous ids, check-cycle failure restoring file, and idempotent add.
