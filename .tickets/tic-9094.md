# Replace deprecated set-output in release workflow

## Need

GitHub Actions warns that `set-output` is deprecated and will be disabled. The release workflow should use Environment Files to pass data between steps instead of `set-output`.

## Acceptance Criteria

- No steps in `.github/workflows/release.yml` use the deprecated `set-output` mechanism.
- Outputs needed for later steps (artifact path/name, upload URL, etc.) are written via the `$GITHUB_OUTPUT` environment file and consumed accordingly.
- Manual and tag triggers continue to work.
- Tests/checks pass.

## Notes

- Updated `.github/workflows/release.yml` to avoid deprecated outputs by using `$GITHUB_OUTPUT` for step data and `gh release` for creating/uploading assets on both tag and manual triggers.
